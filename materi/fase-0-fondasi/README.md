# Fase 0 — Fondasi

> **Tujuan fase:** memiliki landasan Linux, networking, dan Git yang cukup kuat untuk tidak tersesat di fase berikutnya.

## Durasi
Minggu 1–2

## Capaian Fase (Wajib)

- [ ] Nyaman mengetik perintah Linux di terminal tanpa mencari tutorial tiap 5 menit
- [ ] Bisa membaca, mengedit, dan mengejar bug di skrip bash sederhana
- [ ] Bisa membuat VM Linux lewat OrbStack dan mengaksesnya via SSH
- [ ] Bisa menjelaskan konsep DNS, TCP/UDP, firewall secara singkat
- [ ] Bisa bekerja dengan branch, MR, dan conflict di GitLab

## Cara Belajar

1. Mulai dari **Modul 0.1** jika ini pertama kali.
2. Setiap modul punya **materi** + **lab** + **evaluasi**.
3. Isi [_Notes_](https://notes.example.com) pribadi di akhir modul: 3 hal yang dipelajari + 1 hal yang masih bingung.
